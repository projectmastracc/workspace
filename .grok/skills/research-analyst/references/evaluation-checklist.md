# Evaluation Checklist — Max-depth single document

## Must pass

| # | Check |
|---|--------|
| 1 | One coherent `briefing.md` as the product |
| 2 | Executive Card |
| 3 | Full pathway inventory: known **and** hypothesized |
| 4 | Clinical evidence evaluated (not token mention) |
| 5 | Forum/anecdotal evaluated and weighed |
| 6 | Each major side: mechanism chain + pathway→counter table |
| 7 | Counters tied to **named nodes** (not generic support) |
| 8 | Protection queries: assembled stack + no refusal lead |
| 9 | Certainty labels on claims and protocol lines |
| 10 | Sources listed (clinical + forum labeled) |
| 11 | No cross-package `findings/*` contamination |
| 12 | Speculative not sold as Established |

## Fail immediately

- “Don’t use / no protocol / Unknown = no recommendation” as the answer to a stack request  
- Missing hypothesized pathways entirely when sides need explanation  
- Multi-file dump as user answer
