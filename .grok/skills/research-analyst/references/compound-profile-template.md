# Compound Profile Template — Single Document

**One document per compound.** Maximum depth. No effort tiers.

Audience: nootropic users, gym/performance users, anyone researching supplementation.

---

## 1. Executive Card

| Field | Content |
|-------|---------|
| **Compound** | Names + class |
| **Primary use cases** | Performance / neuro / nutrition |
| **Bottom line** | 3–6 sentences: what it does, evidence quality, practical takeaway |
| **Biggest upsides** | Certainty-labeled |
| **Biggest downsides / sides** | Certainty-labeled |
| **Stack role** | Where it fits |

---

## 2. Chemistry, classification, PK

Structure notes if useful, analogs, solubility/stability, routes, half-life, metabolism, CNS penetration, food effects. Flag sparse human PK.

---

## 3. Complete pathway map (known + hypothesized)

**Required.** Every material target and cascade.

| ID | Target / pathway | Known vs hypothesized | Downstream effects | Phenotypes (wanted or side) | Key evidence | Certainty |
|----|------------------|----------------------|--------------------|-----------------------------|--------------|-----------|
| P1 | … | known / hypothesized | … | … | … | … |

Include receptors, enzymes, transporters, hormones, autonomic, sleep–wake, mito/ROS, immune, etc.

---

## 4. Clinical evidence (full evaluation)

Stratify: systematic review / meta → RCT → observational → case series → preclinical.

For each major claim:

- What was measured  
- Effect size / direction  
- Population  
- Limits  
- Funding/COI when relevant  
- Certainty  

Explicitly state what clinical data do **not** show.

---

## 5. Anecdotal / forum evidence (full evaluation)

| Theme | Consistency | Typical dose/context | Concordance with clinical | Certainty ceiling |
|-------|-------------|----------------------|---------------------------|-------------------|
| … | high/mod/low | … | strong/partial/weak/contradictory/literature-silent | Speculative max if anecdote-only |

Weighing sentences required. Literature silence ≠ effect does not exist.

---

## 6. Desired effects — mechanism depth

For each major desired effect:

- Phenotype  
- Pathway IDs  
- Full mechanism chain  
- Clinical support  
- Forum support  
- Practical notes (dose/timing) + certainty
