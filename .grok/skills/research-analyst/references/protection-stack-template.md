# Protection / Counter-Stack Template

**One document.** Use when the user wants neuroprotection, side mitigation, cover stacks, “what counters X,” or full protective protocol for a problem compound (e.g. trenbolone sides).

**Job:** For every commonly reported side → full mechanism → all relevant pathways (known + hypothesized) → compounds/actions that hit those nodes → assembled stack.

**Do not lead with** “don’t use it” or “no protocol.” You may note risk and stop criteria **after** the engineering content.

## 4. Per-side deep dives (THE CORE — repeat for EVERY major side)

### 4.x [Side name, e.g. Insomnia / “trensomnia”]

#### Mechanism (full)

1. **Phenotype detail** — what users report (onset, timing, night sweats vs pure insomnia, etc.)  
2. **Known molecular drivers** — with citations  
3. **Downstream physiology** — step by step  
4. **Hypothesized drivers** — labeled Speculative (e.g. orexin/wake-drive, PR–thermal set-point, GABA_A subunit shifts)  
5. **Cascade diagram or bullet chain** ending at the side  

#### Pathway → counter map

| Pathway node | Why it drives this side | Counter agent / action | How the counter hits the node | Clinical evidence | Forum evidence | Practical notes (dose/timing if known) | Certainty |
|--------------|-------------------------|------------------------|---------------------------------|-------------------|----------------|----------------------------------------|-----------|
| … | … | … | … | … | … | … | … |

**Rules for this table:**

- Multiple counters per node are good.  
- Prefer mechanistically matched counters over generic “sleep support.”  
- If you hypothesize orexin upregulation, list orexin-path or wake-drive counters and label Speculative.  
- Include behavioral/environmental counters where they hit a real node (e.g. cooling → thermogenesis).  
- Include drug–drug or stack conflicts.  

#### Integrated approach for this side

Short paragraph: order of operations (e.g. fix thermal load before sedatives; dose cut before peptides).
