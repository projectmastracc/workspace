### 2.2 Sleep deep-dive (“trensomnia”) — why it breaks

Tren sleep failure is **not one pathway**. It is a stack of parallel hits:

```
P1 AR arousal + low-E2 milieu ──┐
P2 PR / thermoregulatory set    ├──► core heat + autonomic sweat (P3)
P3 thermogenesis / BMR ↑  ──────┘         │
                                          ▼
                              night sweats + thermal arousals
                                          │
P4 GABA_A inhibitory tone ↓ ─────────────► lighter NREM / easy waking
P5 NMDA / anxiety tone ──────────────────► rumination / hypervigilance
P11 monoamine / agitation ───────────────► delayed sleep onset
                    └──────────► PHENOTYPE: trensomnia
P8 sleep loss ──► next-day irritability ──► more AR-driven edge ──► worse sleep
P12 off-cycle low T ──► second wave of insomnia (often worse than on-cycle)
```

| Sleep phenotype | Upstream | Downstream | What actually helps that node | Certainty |
|-----------------|----------|------------|-------------------------------|-----------|
| Night sweats / heat | P2 PR + P3 thermogenesis + low-E2 analogy | Thermal arousals every hour | **Cut dose**; cool room (16–19°C), breathable bedding, fan; evening carb if helpful; avoid alcohol/stim late | Dose/environment **Probable**; PR drug tricks **Speculative** |
| Can’t stay asleep | P3 + P4 GABA + residual heat | Fragmented sleep architecture | Same thermal control; **Mg** if deficient; taurine evening (**Speculative**); avoid phenibut-as-default | **Probable** thermal; **Speculative** GABAergic OTC |
| Wired / mind racing | P1 AR + P11 monoamine | High sleep latency | Earlier last stimulant; dose cut; wind-down; if severe → clinical review | **Probable** |
| Off-cycle insomnia | P12 ASIH | Low-T sleep disruption | Exit plan; time; clinician endocrine eval if prolonged | **Probable** architecture |
| Sleep meds dependence | Compensatory hypnotics | Rebound | Prefer non-benzo first principles; clinician if needed | **Probable** risk of hypnotic overuse |

**Literature anchors:** Klonteig 2024 (AAS sleep pathology, off-cycle worse); Venâncio-type AAS sleep efficiency work (class); Zelleroth 2021 (cellular severity of tren — not sleep-specific); Borecki 2024 (PR, GABA/NMDA, nervous system); forum multi-source “trensomnia” + sweat lore.

### 3.1 Cerebrolysin — independent community finding (this run)

Controlled literature is **silent** on cerebrolysin + trenbolone RCTs. Multi-source community discussion (e.g. r/Cerebrolysin AAS threads; bodybuilding forums) treats cerebrolysin as:

- concurrent “brain support” on harsh cycles, and/or  
- **post-cycle cognitive repair** after AAS (some prefer post over concurrent).

**Weighing:** Report the practice. Concordance **literature-silent**. Efficacy for tren neuroprotection **Speculative**. Silence ≠ “does not work.” Not a substitute for dose discipline. Hits **P6/P7-type** nodes in theory (NTF, anti-excitotoxic, redox narratives from injury models + manufacturer MoA — Schauer 2006 culture ischemia/excitotoxicity; TBI recovery models). Does **not** fix P3 night sweats or P1 AR load.
