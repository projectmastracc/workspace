# In-run mechanism notes for synthesizer (not from findings packages)

## Trenbolone → sleep (chain hypotheses)

Phenotype (high consistency forums + AAS sleep literature): night sweats, fragmented sleep, “trensomnia,” autonomic overdrive.

Plausible mechanism nodes (label Speculative–Probable by link):

1. **Thermogenesis / metabolic rate ↑** → higher core temp, night sweats → sleep fragmentation  
   - AAS can raise nocturnal metabolic expenditure; tren reputation for heat/sweats is multi-source anecdotal  
   - Steroid–thermogenesis literature (general steroids/progestins on BAT/UCP) provides biological plausibility for heat production changes (**Speculative** for tren-specific UCP)

2. **High AR CNS load + non-aromatizing profile** → relative low E2 milieu (vs testosterone cycles)  
   - Community/clinician analogies to menopausal night sweats when E2 is low (**Speculative** for tren)  
   - CNS AR activation associated with arousal/aggression phenotypes in AAS literature

3. **Progestogenic receptor activity** (tren binds PR with high affinity — Borecki review)  
   - Progesterone/progestins modulate thermoregulation and can be pyrogenic in other contexts (**Speculative** transfer)  
   - PR activity also relevant to prolactin narratives (gyno lore) — separate phenotype

4. **GABAergic modulation** (animal AAS literature: GABAA subunit changes, reduced ligand sites → increased excitability)  
   - Could reduce sleep continuity / increase nocturnal arousal (**Speculative** human; **Probable** that AAS alter GABA systems in animals)

5. **Psychological distress / anxiety / agitation** (bidirectional with sleep — Klonteig mediation patterns)  
   - Depression partially mediates AAS–sleep in some models; anxiety/agitation feed insomnia (**Probable** general psychophysiology)

6. **Off-cycle / hypogonadal window** (Klonteig: worse sleep off-cycle)  
   - Hormone levels “wrong in both directions” — high AAS on, suppressed T off → both disturb sleep (**Probable** architecture)
